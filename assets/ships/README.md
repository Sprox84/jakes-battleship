# Naval sprite assets

These production sprites were generated with the built-in image generation tool and then processed locally with the ImageGen chroma-key removal helper. The supplied Battleship screenshot was used as a style and realism reference only.

## Shared prompt

Create exactly one highly realistic, orthographic top-down naval vessel game sprite, viewed directly overhead, with the bow pointing right and stern left. Render it as a photorealistic weathered 3D scale model under soft overcast upper-left lighting, with physically believable ambient occlusion, faded gunmetal naval paint, deck plating, hatches, railings, vents, antennas, equipment, restrained rust and salt streaks, and a crisp silhouette. Center the full vessel on a perfectly flat solid `#ff00ff` chroma-key background with generous padding. No ocean, wake, smoke, fire, explosion, grid, text, label, watermark, border, cast shadow, reflection, or use of the key color on the vessel.

## Subject prompts

- `carrier`: Fleet aircraft carrier with a long flight deck, landing markings, parked aircraft, elevators, starboard island, radar mast, and deck-edge equipment.
- `battleship`: Heavy armored battleship with main gun turrets, secondary batteries, bridge tower, rangefinders, radar masts, funnels, lifeboats, and anti-aircraft mounts.
- `cruiser`: Slim light cruiser with main gun turrets, compact bridge, radar mast, funnels, lifeboats, torpedo equipment, and anti-aircraft details.
- `destroyer`: Modern destroyer with a slim fast hull, bow gun, angular bridge, radar mast, exhaust stacks, missile and torpedo launchers, liferafts, helicopter deck, and stern equipment.
- `submarine`: Surfaced diesel-electric attack submarine with a dark pressure hull, narrow upper deck, sail, periscopes, hatches, panel seams, and control surfaces.

The `-v.png` files are locally generated clockwise rotations for lossless vertical placement.
